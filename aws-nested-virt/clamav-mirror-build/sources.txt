# clamav-mirror-build sources — 3rd-party / non-mainline ClamAV feeds
# we mirror through the the ruleset CDN.
#
# Standard Cisco-Talos CVDs (main.cvd, daily.cvd, bytecode.cvd) are
# NOT mirrored here — Cisco's own DatabaseMirror network is the right
# distribution path for those.  This file lists the feeds the existing
# CAPE host's /etc/clamav/freshclam.conf reaches via DatabaseCustomURL
# entries, which we move behind our CDN.
#
# Format: one URL per line.  Comments + blanks allowed.  The URL
# basename becomes the on-CDN filename
# (e.g., http://.../sanesecurity/junk.ndb → /clamav-extra/junk.ndb).
#
# Add new feeds by appending a line + committing to main; the workflow's
# push trigger rebuilds.
